# Community code of conduct

Graphe aims to build useful, trustworthy software through careful engineering and respectful collaboration.

When participating in issues, pull requests and project discussions:

- Be constructive, patient and specific. Critique ideas and changes rather than people.
- Welcome contributors with different levels of experience and different backgrounds.
- Avoid harassment, insults, threats, discriminatory conduct and unwanted personal attacks.
- Respect privacy; do not share personal, confidential or private project information without permission.
- Help the maintainers keep technical and security discussions focused and evidence-based.

Maintainers may edit or remove comments, close discussions, decline contributions, or restrict participation to protect the community. Report concerns through an appropriate private maintainer contact if one is available; do not publicize personal details.

The same expectations apply to maintainers and contributors.
