# Security policy

Graphe is a browser-based editor backed by a Rust/WASM document engine. Imported office documents, embedded images, storage and conversion logic are security-sensitive.

## Reporting

**Please do not disclose vulnerabilities publicly before maintainers have had an opportunity to investigate.**

After the public repository launches, use **GitHub → Security → Report a vulnerability** if private vulnerability reporting is enabled. If it is not enabled, open a non-sensitive issue requesting a private reporting channel; include no exploit details or sensitive data in that public issue.

A helpful private report includes affected version/commit, file format and minimal synthetic reproduction, security impact, expected versus observed behavior, and any known workaround. Do not upload confidential documents.

## Supported versions

The open-source release has **not happened yet**; no public version or support window is currently promised. The maintainers will update this section on first public release.

## Handling

The maintainer will review and prioritize credible reports, coordinate any fix and disclosure, and credit researchers who request recognition. Response time and bug-bounty payments are not guaranteed.

Security-sensitive code changes require review and appropriate regression tests. Security testing must use controlled data and authorized systems only.
