## Correctness of commonly confused licensing claims

- **Closed source with permissive dependencies:** usually compatible if all conditions on distribution and notices are met. A crate marked `MIT OR Apache-2.0` does not automatically require Graphe itself to become open source.
- **Font licenses:** bundled OFL fonts retain their own terms; original documents made using the fonts are not automatically placed under the OFL. Review the [OFL](https://openfontlicense.org/) and [official FAQ](https://openfontlicense.org/ofl-faq/) before modifying or embedding fonts into new deliverables.
- **Office formats:** implementing a documented DOCX file format is not the same thing as copying Microsoft Word's code or bundling Microsoft fonts. A technical standard does not eliminate all possible patents, trademarks, or licensing conditions for extensions and assets.
- **Free application:** charging users nothing does not eliminate notice requirements or redistribution obligations.
